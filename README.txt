XLITA — REAL 3D SCROLL WEBSITE

This package includes an actual GLB 3D car asset (assets/xlita.glb), not only a 2D image.

RUN ON CHROME (recommended):
1. Extract this ZIP.
2. Open a terminal/Command Prompt in this folder.
3. Run: python -m http.server 8000
4. Open Chrome and go to: http://localhost:8000
5. Scroll slowly from top to bottom.
6. Drag with mouse/finger to manually rotate the car.

If Python is unavailable, use any simple local static HTTP server. Do not double-click index.html because browser security rules can block module/model loading from file://.

SCROLL SEQUENCE:
01 Arrival
02 360 exterior
03 Front design
04 Side profile
05 Rear aero
06 Doors open
07 Cabin interior
08 Engine bay
09 Final hero

The 3D model is an original procedural XLITA concept model built for this demo. It is separate named geometry so the webpage can animate doors, hood, wing and camera.
